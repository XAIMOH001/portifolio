# My Portfolio Website

A modern, interactive portfolio website built with TypeScript, showcasing my projects and skills.

**Live Demo:** [simon-chau-mburu.vercel.app](https://simon-chau-mburu.vercel.app/)

## About

This is my personal portfolio website where I showcase my work, projects, and professional experience. The site is designed to be modern, responsive, and user-friendly.

## Getting Started

### Prerequisites
- Node.js
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/XAIMOH001/portifolio.git

# Navigate to project directory
cd portifolio

# Install dependencies
npm install
# or
yarn install
```

### Development

```bash
# Start development server
npm run dev
# or
yarn dev
```

### Build

```bash
# Build for production
npm run build
# or
yarn build
```

## Deployment

This project is deployed on [Vercel](https://vercel.com/). Any push to the main branch automatically triggers a deployment.
